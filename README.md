# Страж — локальная проверка файлов

Настольное приложение для CachyOS (есть и исходники версии для Windows). Проверяет файлы и папки **полностью локально**: ничего не загружается, не изменяется и не удаляется, файлы не запускаются. Интерфейс на русском, графитовый фон, фиолетовые кнопки, мятные индикаторы; красный — только для обнаружений.

> **Совпадений нет ≠ файл безопасен.** Страж — вспомогательная проверка, а не полноценный антивирус.

## Быстрый старт (Linux)

Откройте **Страж** в меню приложений, либо запустите `~/.local/bin/strazh` или `./run.sh` из папки проекта.

Повторная установка готовой сборки: `./scripts/install.sh` — только для текущего пользователя, в `~/.local/share/strazh`, без фоновых служб. Нужны системные `gtk3` и `webkit2gtk-4.1`; ClamAV уже входит в комплект. Rust, Node и Python для запуска не нужны.

## Простой ответ

После проверки Страж показывает один из шести ответов крупно, цветом и анимацией: **«Вирусов не найдено»** (мятный), **«Найдены вирусы»** (красный), **«Есть подозрительные файлы»** (жёлтый), **«Проверено не всё»**, **«Проверка остановлена»**, **«Нечего проверять»**. В списке по умолчанию показаны только проблемные файлы.

## Что умеет

Выберите файлы или папку, способ проверки и число потоков, затем запустите.

| Способ | Что проверяется |
| --- | --- |
| Быстрые отпечатки + список | Потоковый SHA-256, тип файла, хеш EICAR, импортированные хеши |
| Обычный анализ + список (по умолчанию) | Всё выше, плюс шаблоны EICAR на границах буферов, несоответствие расширения и типа, закодированные команды, связки «скачать и выполнить» в скриптах |
| Глубокая: обычный анализ + ClamAV | Обычный анализ и потоковая передача в ClamAV (его антивирусная база, архивы). **Выбирается автоматически, когда ClamAV готов** |

- Находки статического анализа помечаются **«Проверить»**, а не «вредоносное».
- Архивы без ClamAV не распаковываются, только определяется их формат. Эмуляции нет.
- **ClamAV встроен** в папку `clamav/` (clamd, freshclam, библиотеки, база `daily.cvd`; ~70 МБ, лицензия GPL-2.0). Страж сам запускает личный `clamd` пользователя без root и системной службы, сокет `$XDG_RUNTIME_DIR/strazh-clamd.sock`, и останавливает его при закрытии. ClamAV запускается первым делом при открытии приложения; загрузка базы занимает около 10 секунд, до этого работает обычная проверка. Чтобы ClamAV был готов сразу, установите с `./scripts/install.sh --clamav-service` — служба пользователя (без root) загружает ClamAV при входе в систему и держит ~700 МБ ОЗУ; отключение: `systemctl --user disable --now strazh-clamd`. Ограничения ClamAV по размеру сняты (поток до 4 ГБ); временные файлы ClamAV — в `~/.cache/strazh/clamd-tmp`, для больших файлов нужно столько же свободного места. При запуске, если база старше суток, встроенный `freshclam` тихо обновляет её (нужен интернет). Системный `clamav` используется только как запасной вариант.
- В Windows-версии ClamAV тоже встроен (clamd.exe на 127.0.0.1:3311, только пока открыто окно).
- Дополнительные признаки «Проверить»: скрытый PowerShell, `certutil`/`bitsadmin`/`mshta`, reverse shell, запутанный JavaScript, двойное расширение (`счёт.pdf.exe`). Признаки ищутся во всём файле, без ограничения размера.
- Проверяемые файлы не отправляются в сеть. FreshClam может скачивать обновления антивирусной базы; из интерфейса убраны проверка URL/доменов/IP, аккаунты, чат, WebAssembly, JS-воркеры и внутренний HTTP-сервер.

### Встроенная база IOC

При запуске загружаются 1175 уникальных SHA-256 индикаторов из публичной базы LOKI / Signature-Base (Florian Roth / Neo23x0 и участники). Источник: <https://github.com/Neo23x0/signature-base/blob/master/iocs/hash-iocs.txt>, лицензия Detection Rule License 1.1: <https://raw.githubusercontent.com/Neo23x0/signature-base/master/LICENSE>.

- Файл `app/engine/data/loki-sha256.txt` — все SHA-256 из `hash-iocs.txt` LOKI на 08.11.2026 (MD5 и SHA-1 в приложении не используются). База не обновляется автоматически.
- Есть индикаторы инструментов двойного назначения, поэтому совпадения нужно проверять вручную. В метках сохранено указание LOKI / Neo23x0.
- Свои списки добавляются к встроенному. Вредоносные файлы приложение не скачивает.
- MalwareBazaar рассмотрен, но актуальные экспорты требуют Auth-Key (<https://bazaar.abuse.ch/export/>), старый адрес возвращает HTTP 410.

### Свой список SHA-256

Кнопка **Импорт списка SHA-256**. Каждая непустая строка: 64 символа SHA-256, затем необязательная метка. Строки с `#` — комментарии.

```text
# Формат; используйте хеши из надёжного источника
0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef Пример
```

Размер и число хешей не ограничены; одна строка — до 4096 байт. Ошибка импорта не затрагивает прежний список. Список хранится до закрытия приложения, после перезапуска импортируйте заново.

### Автопроверка загрузок

«Включить автопроверку» следит за `~/Downloads`, пока приложение открыто; повторное нажатие выключает режим и останавливает текущую проверку. После перезапуска режим выключен, служба не устанавливается.

- Обычный анализ, два потока, загруженный список хешей.
- Файл проверяется после 10 секунд без изменений; частичные загрузки пропускаются; существующие файлы тоже проверяются.
- Лимиты: 10 000 файлов, глубина 32 папки. Результаты приходят пакетами в общий список.

Без нажатия кнопки проверки запускаются только вручную.

## Память и скорость

- По умолчанию 2 потока; 1 — минимум ОЗУ, 4 — быстрее на SSD.
- Каждый поток переиспользует буфер чтения 256 КиБ плюс до ~256 КиБ на активный файл для анализа. Файлы целиком не загружаются.
- Очереди ограничены: 32 пути и 64 результата. Обход папок потоковый, вложенность до 128. Символические ссылки и спецфайлы пропускаются; ошибки чтения и изменение файла во время проверки сообщаются.
- Лимита строк нет: в списке все результаты (по умолчанию видны только проблемные). «Очистить» освобождает память. Подтверждение обновлений интерфейса не даёт медленному рендереру копить пакеты.
- Кэш страниц WebKit отключён, но базовое потребление WebKit остаётся. Автономный сканер ниже его не имеет.

## Консольный сканер `vt-scan`

Не использует GTK и WebKit, выводит JSON-строки и итог.

```sh
./app/vt-scan --mode static --workers 2 /путь/к/папке
./app/vt-scan --mode hashes --workers 1 --quiet /путь/к/файлу
./app/vt-scan --signatures /путь/к/hashes.txt /путь/к/папке
```

Коды выхода: `0` — находок нет, `1` — совпадение или находка «Проверить», `2` — проверка неполная или ошибка. Те же опции принимает приложение: `./run.sh --scan PATH`.

## ClamAV (необязательно)

В этой системе ClamAV не установлен. Для режима нужен локальный `clamd` с готовой базой. Страж подключается по Unix-сокету и передаёт файл в ходе того же чтения, что и для хеширования: процессы на файл не запускаются, файлы не выгружаются.

Типичные пути сокета определяются сами; иначе: `VIRUSTOTAL_CLAMD_SOCKET=/path/to/clamd.sock ./run.sh`. Ошибки подключения, прав, таймауты и превышение лимитов считаются неполной проверкой, даже если другая проверка нашла совпадение. Служб приложение не ставит и не запускает. Документация: [сканирование](https://docs.clamav.net/manual/Usage/Scanning.html), [протокол INSTREAM](https://docs.clamav.net/manual/Usage/ClamdProtocol.html).

## Сборка и проверка

```sh
cd app
cargo test --workspace --offline
cargo clippy --workspace --all-targets --offline -- -D warnings
cargo build --release --offline
node tests/ui-smoke.cjs
python3 tests/cli-smoke.py
cp target/release/strazh strazh
cp target/release/vt-scan vt-scan
```

- Зависимости Rust уже в кэше; на чистой машине уберите `--offline`.
- Только консольный сканер: `cargo build --release --bin vt-scan --offline`.
- Node и Python нужны лишь для тестов разработки.
- Тест скорости: `python3 app/tests/benchmark.py` из корня проекта, результат в `checks/native-scan-benchmark.json`. Измеряется только родной сканер на восьми сгенерированных файлах по 32 МиБ при тёплом кэше; ОЗУ интерфейса, холодный диск, большие списки и ClamAV не измеряются.
- Внешний вид на реальном экране в этой среде не проверялся.

Резервные копии: `../virustotal-local-before-native-scanning.tar.gz` (до перехода на родное сканирование) и `../virustotal-com-web-backup.tar.gz` (исходная веб-версия).

## Структура проекта

| Путь | Назначение |
| --- | --- |
| `app/` | Rust-приложение: `src/` (GTK/WebKit, CLI, автопроверка), `engine/` (движок и база хешей), `ui/` (интерфейс), `tests/` |
| `clamav/` | Встроенный ClamAV (бинарники, библиотеки, база) |

## Сайт приложения

Русскоязычный сайт: [website/dist/index.html](website/dist/index.html). Лёгкая Linux-сборка, исходники и SHA-256 находятся в `website/dist/downloads`. Полный пакет ClamAV в лёгкую сборку не входит.
