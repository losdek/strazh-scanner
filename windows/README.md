# Страж для Windows 10/11 x64

Статус: кросс-сборка с Linux выполнена — готов **переносимый пакет** `windows/dist/Strazh-Windows-x64-portable.zip` (распакуйте и запустите `Strazh.exe`; нужен установленный WebView2, он есть в Windows 11 и большинстве Windows 10). `vt-scan.exe` собран статически (MinGW), приложение на C# — self-contained. **Ни один из файлов не запускался на Windows** (в wine проверка зависла), установщик `Strazh-Setup-x64.exe` не собран: Inno Setup требует Windows. Всё нужно проверить на Windows.

## Что входит в установщик

- Rust-сканер `vt-scan.exe`, встроенная база 1175 SHA-256 и статические проверки.
- Русский интерфейс с графитовой, фиолетовой и мятной палитрой; оболочка WinForms/WebView2 на C#.
- Собственная копия .NET runtime: пользователю не нужен SDK или отдельная установка .NET.
- Полный офлайн-установщик Microsoft WebView2, запускаемый только при отсутствии runtime. Такой способ распространения описан в [документации Microsoft](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution).
- Ярлык в меню «Пуск», дополнительный ярлык рабочего стола и удаление через настройки Windows.

Установка для текущего пользователя: `%LOCALAPPDATA%\Programs\Strazh`. Пользовательские данные: `%LOCALAPPDATA%\Strazh`. Подпись коммерческим сертификатом не настроена.

Автопроверка включается кнопкой и работает, пока открыто приложение. Она использует системную папку загрузок, включая перенесённую, пропускает временные файлы и ждёт 10 секунд стабильного размера. Автозапуск и служба не устанавливаются. ClamAV для Windows (официальная сборка Cisco Talos 1.5.4, SHA-256 проверен) входит в пакет вместе с базой `daily.cvd`: Страж запускает `clamd.exe` на 127.0.0.1:3311, пока открыто окно, и останавливает при закрытии; база обновляется `freshclam.exe`, если ей больше суток. Хеши — небольшой встроенный снимок, а не полная антивирусная база; отсутствие совпадения не доказывает безопасность файла.

## Получить установщик через GitHub Actions

Загрузите проект в свой GitHub-репозиторий вместе с `.github/workflows/windows.yml`. В Actions выберите **Windows installer → Run workflow**. После успешного выполнения скачайте артефакт **Strazh-Windows-x64**, распакуйте и запустите `Strazh-Setup-x64.exe`.

Workflow собирает приложение, проверяет Rust-движок, устанавливает пакет в тестовый каталог и проверяет установленный сканер. Проверки интерфейса вручную всё ещё нужны. Публикация репозитория и запуск workflow из этой среды не выполнялись.

## Собрать локально на Windows

На компьютере сборки нужны PowerShell 7, Rust stable MSVC с Visual Studio C++ Build Tools, .NET 10 SDK и Inno Setup 6. Интернет нужен для получения зависимостей и WebView2 при сборке. На целевом компьютере эти инструменты не нужны.

Из корня проекта:

```powershell
pwsh -File windows/build.ps1
```

Результат: `windows/dist/Strazh-Setup-x64.exe`. Без установщика: `pwsh -File windows/build.ps1 -SkipInstaller`; переносимая папка `windows/publish` требует установленный WebView2.
